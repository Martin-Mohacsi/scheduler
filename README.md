# SchedUler

A personal app for schedules, time management and progress, with connections to learning and training apps.

It runs as a responsive web app on desktop and phone (Chrome on Android and desktop, Chrome and Safari on iOS) and can be added to the home screen like an installed app.

## Files

- `index.html`: the app
- `manifest.webmanifest`, `sw.js`, `icons/`: what lets it install to a home screen and open offline

No build step: the site is served straight from the `main` branch with GitHub Pages.
